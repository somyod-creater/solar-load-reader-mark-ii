# Sample data — โหลดบ้านเรือน 1 เดือน

ไฟล์ทดสอบสำหรับ Solar Load Reader Mark II

## `household_load_sep2026.xlsx`

| รายการ | ค่า |
|---|---|
| ประเภท | บ้านเรือน (residential) |
| ช่วง | 1–30 ก.ย. 2026 |
| ความละเอียด | รายชั่วโมง (720 จุด) |
| คอลัมน์ | `Time`, `Load (kW)` |
| พลังงานรวม | ~880 kWh / เดือน (~29 kWh/วัน) |
| Peak | ~4.2 kW (เย็น) |

รูปแบบโหลดเย็นสูงตอนเย็น–ค่ำ ตามบ้านชานเมืองไทย (แอร์ / ทำอาหาร / ไฟ)

มี CSV สำรองชื่อเดียวกันถ้าเปิด Excel ไม่ได้

## วิธีทดสอบในแอป

1. เปิดแอป → Input Data  
2. อัปโหลด `household_load_sep2026.xlsx` ที่ช่อง Load profile  
3. ตั้งขนาดบ้าน เช่น **3–5 kWp**, Inverter เท่ากับ kWp, ประเภทค่าไฟบ้าน `1.2.2`  
4. กด **Run** ดู Summary  

ผลอ้างอิงจากรอบทดสอบ (On-grid, 35 ฿/Wp, tariff บ้าน TOU):

| ขนาด | Self-consumption | ประหยัด/ปี | Payback โดยประมาณ |
|---|---|---|---|
| 3 kWp | ~51% | ~฿12,900 | ~8.1 ปี |
| 5 kWp | ~34% | ~฿14,500 | ~12.1 ปี |
| 8 kWp | ~23% | ~฿15,400 | ~18.2 ปี |
